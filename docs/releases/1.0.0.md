# Launchpod 1.0.0

The first public release of Launchpod, a native macOS application launcher for Apple Silicon.

- Browse, search, and organize applications in a familiar grid with pages and folders.
- Open the launcher from the Dock, menu bar, global keyboard shortcut, or configurable trackpad gestures.
- Customize the grid, app icon, and English or Korean interface.
- Import supported legacy Launchpad layouts and export or import layouts as JSON.
- Check for updates from the menu bar with Sparkle, including optional automatic update checks.
- Adjacent pages follow the pointer from the first background drag movement.

Requires an Apple Silicon Mac (arm64) running macOS 12.0 or later. Accessibility permission is required for trackpad gestures.

## Install

Download **Launchpod-1.0.0-arm64.dmg**, open it, and drag Launchpod to Applications. The app and disk image are Developer ID signed and notarized by Apple.

Or install from the Homebrew tap:

```sh
brew install --cask elixirevo/tap/launchpod
```
