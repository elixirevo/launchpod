# Launchpod 1.3.1

Improved window presentation with MacAppEssentials 0.5.1.

- Settings, onboarding, and terms windows are brought forward more reliably when requested, including after restoring a minimized window or waiting for app activation.
- Only the latest window request receives delayed focus. Closing or minimizing it, selecting another window, or switching away cancels the pending request.
- Launchpod remains a menu bar app. Existing layouts, settings, onboarding completion, and terms acceptance are preserved.

Requires macOS 13.0 or later and an Apple Silicon Mac (arm64).

## Install or update

Download **Launchpod-1.3.1-arm64.dmg**, open it, and drag Launchpod to Applications. The app and disk image are Developer ID signed and notarized by Apple.

Existing users can choose **Check for Updates…** from the menu bar or Settings. For a Homebrew installation:

```sh
brew update
brew upgrade --cask elixirevo/tap/launchpod
```

For a new installation, use `brew install --cask elixirevo/tap/launchpod`.
