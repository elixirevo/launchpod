# Launchpod 1.3.0

A new settings experience, guided setup, and better app discovery and organization.

**Requires macOS 13.0 or later and an Apple Silicon Mac (arm64).** The minimum macOS version has increased from 12.0.

## Settings and setup

- Redesigned settings with General, Features, Keyboard Shortcuts, Permissions, Updates, Help & Support, and About pages. Grid, app icon, layout, and app-library controls live in Features; gestures and hot corners live in Keyboard Shortcuts.
- Guided first-run setup covers opening Launchpod, organizing apps, terms agreement, Accessibility, and optional crash reports. Reopen the introduction from Help & Support at any time.
- English and Korean Terms of Use and Privacy Policy are available offline in Help & Support. Updated terms require explicit agreement before app features start.
- Optional Sentry crash reporting is off by default. Changes take effect after restarting the app.
- Fixed first-time registration for Launch at Login.

## App discovery and organization

- Find system utilities such as Keychain Access, plus tools inside app bundles, including Xcode's Icon Composer and Simulator.
- New layouts place macOS apps and a Tools folder first, followed by user-installed apps on separate pages. The default Tools folder contains only utilities bundled with macOS; separately installed utilities and Xcode tools stay outside it.
- Existing app arrangements are preserved. Choose **Settings → Features → Layout → Reset Layout…** to rebuild the default arrangement after confirmation. This removes custom folders while keeping hidden apps, unavailable apps, and other settings. Undo and Redo are supported.
- **General → Restore Defaults → Features** restores grid, app icon, search locations, and hidden-app settings while keeping app order and folders.

## Everyday use

- Normal startup leaves Launchpod running in the menu bar without opening the launcher. Click the icon or use a configured shortcut, gesture, or hot corner to open it. Required setup and terms still appear when needed.
- The menu bar's Open Launchpod action is separated from Settings by a divider.

## Install or update

Download **Launchpod-1.3.0-arm64.dmg**, open it, and drag Launchpod to Applications. The app and disk image are Developer ID signed and notarized by Apple.

Existing users on macOS 13.0 or later can choose **Check for Updates…** from the menu bar or Settings. For a Homebrew installation:

```sh
brew update
brew upgrade --cask elixirevo/tap/launchpod
```

For a new installation, use `brew install --cask elixirevo/tap/launchpod`.
