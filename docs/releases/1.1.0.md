# Launchpod 1.1.0

Open Launchpod from a screen corner, and dismiss it with one click on another display.

## New

- Choose any of the four hot corners in Settings. Each corner can be enabled independently, and opens Launchpod on the display where you move the pointer.
- Hot corners activate once per visit and do not open the launcher during a mouse drag. All corners are off by default.
- Settings include English and Korean guidance for avoiding duplicate macOS hot corner actions, and now scroll so every setting remains accessible on smaller screens.

## Fixed

- Clicking the desktop on another display closes the launcher even when the launcher does not have keyboard focus or its Settings window is still open.
- Dismissing the launcher through an outside click preserves focus on the window or desktop you clicked.

To use hot corners, keep Launchpod running and select your preferred corners in **Settings → Hot corners**. Set those same corners to **“–”** in **System Settings → Desktop & Dock → Hot Corners** to avoid running both actions. Launchpod does not change your macOS hot corner settings.

Requires an Apple Silicon Mac (arm64) running macOS 12.0 or later. Accessibility permission is required for trackpad gestures.

## Install

Download **Launchpod-1.1.0-arm64.dmg**, open it, and drag Launchpod to Applications. The app and disk image are Developer ID signed and notarized by Apple.

Existing users can choose **Check for Updates…** from the menu bar. For a Homebrew installation:

```sh
brew update
brew upgrade --cask elixirevo/tap/launchpod
```

For a new installation, use `brew install --cask elixirevo/tap/launchpod`.
