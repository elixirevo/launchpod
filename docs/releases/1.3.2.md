# Launchpod 1.3.2

Fixed missing apps such as BetterDisplay in the launcher catalog.

- Standalone installed apps now appear even when they declare background-only execution (`LSBackgroundOnly`), including BetterDisplay installed through Homebrew.
- Internal login helpers, background-only embedded tools, and background-only XPC services remain excluded. Symlinks and directly added search paths cannot bypass the internal helper exclusions.
- Existing app layouts, folders, hidden apps, and preferences are preserved. Newly discovered apps appear on the next catalog scan.

Requires macOS 13.0 or later and an Apple Silicon Mac (arm64).

## Install or update

Download **Launchpod-1.3.2-arm64.dmg**, open it, and drag Launchpod to Applications. The app and disk image are Developer ID signed and notarized by Apple.

Existing users can choose **Check for Updates…** from the menu bar or Settings. For a Homebrew installation:

```sh
brew update
brew upgrade --cask elixirevo/tap/launchpod
```

For a new installation, use `brew install --cask elixirevo/tap/launchpod`.
